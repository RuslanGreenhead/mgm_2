# Original RFM Config Audit

Scope: original RFM values are taken only from `external/riemannian-fm/configs/train.yaml`, `external/riemannian-fm/configs/experiment/*.yaml`, `external/riemannian-fm/README.md`, `external/riemannian-fm/train.py`, `external/riemannian-fm/evaluate.py`, and `external/riemannian-fm/manifm/datasets.py`. No long training runs were launched, and no training scripts were changed.

Notes:

- Values below are resolved with inheritance from `configs/train.yaml`. In particular, omitted `optim.num_iterations` means `1000000`, omitted `val_every` means `1000`, omitted `optim.wd` means `0.0`, and omitted validation batch means `20000`.
- `train.py` maps `optim.num_iterations` to Lightning `max_steps` and `val_every` to `val_check_interval`.
- README's official training template is `python train.py experiment=<experiment> seed=0,1,2,3,4 -m`. The commands below keep that exact shape and add only the datadir override needed by each data family.
- `evaluate.py` exposes `nll <checkpoint>` and `visualize <checkpoint> [--all]`, but the allowed official files do not define an NFE override or per-config NFE value. Therefore NFE is marked `not specified` for every config.
- Current-prior-run sufficiency is a step-budget comparison against local prior artifacts: current real Earth/Torus runs are at most 800 steps, toy `torus2d` at most 4000, toy `spd`/`hyperbolic` at most 2000, and no matching mesh run was found. These are all below the official budgets in this table.
- There is no separate `spd.yaml` in `configs/experiment`; the official SPD config present here is `wrapped_spd.yaml`.
- The allowed official files do not contain a high-dimensional sweep list for `wrapped_torus` or `wrapped_spd`; the table records the explicit YAML defaults (`wrapped.dim=5` and `wrapped.dim=3`). Extra dimensions would be Hydra overrides, not additional author defaults found in this local source set.

## Earth/Torus config check

- Earth configs are `volcano`, `earthquake`, `fire`, and `flood`. They all route to `EarthData` subclasses on `Sphere`, use `earth_datadir`, and inherit `1000000` iterations and `val_every=1000`.
- Torus configs are `general`, `glycine`, `proline`, `prepro`, and `rna`. `general/glycine/proline/prepro` use Top500 torsion data on `FlatTorus` dim 2; `rna` uses RNA torsions on `FlatTorus` dim 7. They all inherit `1000000` iterations and `val_every=1000`.
- Local Earth CSVs and Top500/RNA aggregated TSVs are present. Current local prior Earth/Torus training budgets are only smoke/pilot scale, so they are not enough to match official RFM budgets.

## Evaluation templates

Run official likelihood evaluation after training:

```bash
python evaluate.py nll <path-to-checkpoint.ckpt>
```

Run official visualization:

```bash
python evaluate.py visualize <path-to-checkpoint.ckpt>
python evaluate.py visualize --all <path-to-checkpoint.ckpt>
```
